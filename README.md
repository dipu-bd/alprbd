# ALPR-Bangladesh

Automated Bangla License Plate Detection and Recognition - Implementation

### Build Instruction

- **Install Anaconda**: Follow [this tutorial](https://docs.continuum.io/anaconda/install).
- Make sure to set up environment variables.
- Restart your PC if environment variable not working after being set.
- Open terminal and go to project folder.
- Run `./build.sh`to start the project.
